# 隐私与发布边界

公开仓库只发布审核工具源码、通用文档、合成示例生成器和测试。不包含真实数据集、标注回传、源图片、模型权重、团队成员信息、审核清单、本机配置、浏览器存储、运行日志或访问凭据。

方桌几何模块为独立实现，没有打包私有仓库源码。没有从旧工作目录复制 `.git`，公开提交从全新历史开始。提交身份使用 GitHub noreply 邮箱；不公开本机 Git 配置中的邮箱。

`demo_data/`、`datasets/`、`data/`、`.runtime/`、`.review_deleted/`、`.env*`、日志与压缩包默认被 Git 忽略。`.gitignore` 是防误提交措施，不能代替人工检查；共享自有数据前仍需检查文件及其历史。

正常使用中，JSON、草稿、删除记录和日志可能保存数据集路径及原有元数据。它们留在本机，不会由本工具发送到远程服务。请不要将这些内容直接附到公开 issue。也不要将只面向本机信任环境的服务改为公网监听。
